# EX-014-002 - Rôle du solveur

## Énoncé

Pourquoi le solveur fait-il partie du comportement réel d'une Neural ODE ?

## Ce que l'exercice vérifie

L'exercice vérifie que le solveur n'est pas un détail technique invisible. Dans une Neural ODE, le modèle définit une dynamique, mais le solveur décide comment elle est suivie numériquement.

## Solution détaillée

Une Neural ODE définit :

```text
dh(t)/dt = f_theta(h(t), t)
```

Mais pour obtenir `h(t1)` à partir de `h(t0)`, il faut intégrer cette équation. C'est le rôle du solveur.

Le solveur choisit :

- les pas de temps ;
- les tolérances d'erreur ;
- la méthode numérique ;
- le nombre d'évaluations de `f_theta` ;
- parfois la façon de gérer les zones difficiles.

Ces choix influencent directement :

```text
précision
coût
latence
stabilité
gradients
reproductibilité
```

Si la dynamique apprise est difficile à intégrer, le solveur peut prendre beaucoup de petits pas. Le modèle devient plus coûteux, même si l'architecture semble compacte.

Deux solveurs différents peuvent produire des trajectoires légèrement différentes, surtout si les tolérances ou la dynamique sont délicates. Donc le solveur fait partie du contrat expérimental.

## Points importants

- Le solveur transforme la dérivée en trajectoire.
- Il influence coût et précision.
- Le nombre d'évaluations de `f_theta` peut varier.
- Une dynamique instable peut rendre l'intégration coûteuse.
- Il faut documenter le solveur dans les expériences.

## Prolongement

Quand on compare une Neural ODE à un RNN ou un ResNet, il faut inclure le coût du solveur. Sinon, on compare une idée mathématique à une exécution incomplète.
