# EX-014-003 - NFE

## Énoncé

Que peut indiquer un NFE très élevé pendant l'entraînement ?

## Ce que l'exercice vérifie

L'exercice vérifie la lecture du nombre d'évaluations de fonction. Dans une Neural ODE, le NFE indique combien de fois le solveur appelle `f_theta`.

## Solution détaillée

`NFE` signifie généralement :

```text
Number of Function Evaluations
```

Si le NFE est très élevé, cela peut indiquer que le solveur travaille fort pour intégrer la dynamique.

Causes possibles :

1. La dynamique apprise est raide ou difficile.
2. Les tolérances du solveur sont trop strictes.
3. La fonction `f_theta` produit des variations rapides.
4. Le solveur choisi est mal adapté.
5. L'entraînement pousse le modèle vers des trajectoires instables.

Un NFE élevé n'est pas automatiquement un échec. Il peut refléter une dynamique réellement complexe. Mais il augmente le coût d'entraînement et d'inférence.

Diagnostic possible :

```text
logger NFE par batch
comparer solveurs et tolérances
observer les trajectoires
ajouter régularisation
tester une architecture plus simple
```

Si le NFE explose au fil de l'entraînement, il faut se demander si le modèle apprend une solution numériquement pénible.

## Points importants

- Le NFE mesure les appels à `f_theta`.
- Un NFE élevé signifie souvent intégration coûteuse.
- La cause peut être dynamique difficile, tolérance stricte ou solveur inadéquat.
- Il faut le suivre comme une métrique système.
- Un bon score de tâche peut cacher un coût numérique élevé.

## Prolongement

Dans un contexte production, le NFE peut devenir une métrique d'acceptation. Une Neural ODE qui réussit la tâche mais avec un NFE imprévisible peut être difficile à déployer avec une latence garantie.
