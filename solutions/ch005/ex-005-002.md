# EX-005-002 - Interpréter une frontière

## Énoncé

Pour la frontière `3*x_1 - 2*x_2 + 1 = 0`, expliquez comment le poids de `x_1`, le poids de `x_2` et le biais influencent la décision.

## Ce que l'exercice vérifie

L'exercice vérifie que la frontière linéaire n'est pas seulement une formule. C'est un contrat géométrique : chaque poids pousse la décision dans une direction, et le biais déplace la frontière.

## Solution détaillée

La fonction de score est :

```text
z = 3*x_1 - 2*x_2 + 1
```

La frontière de décision est l'ensemble des points où :

```text
z = 0
```

Donc :

```text
3*x_1 - 2*x_2 + 1 = 0
```

Le poids de `x_1` est `3`. Quand `x_1` augmente, le score augmente. Cette feature pousse donc vers la classe positive si le seuil est `z >= 0`.

Le poids de `x_2` est `-2`. Quand `x_2` augmente, le score diminue. Cette feature pousse donc vers la classe négative.

Le biais est `1`. Il ajoute une valeur constante au score, peu importe l'entrée. Il déplace la frontière dans l'espace. Sans biais, la frontière passerait par l'origine :

```text
3*x_1 - 2*x_2 = 0
```

Avec le biais, la frontière est décalée :

```text
3*x_1 - 2*x_2 = -1
```

On peut isoler `x_2` :

```text
3*x_1 - 2*x_2 + 1 = 0
-2*x_2 = -3*x_1 - 1
x_2 = 1.5*x_1 + 0.5
```

La droite a donc une pente de `1.5` et une ordonnée à l'origine de `0.5`.

Ce calcul donne une lecture géométrique : la frontière sépare le plan en deux demi-espaces. D'un côté, `z` est positif. De l'autre, `z` est négatif.

## Points importants

- `x_1` pousse positivement le score.
- `x_2` réduit le score.
- Le biais décale la frontière.
- Le vecteur de poids définit l'orientation de la frontière.
- Le signe du score détermine la décision si on utilise un seuil à zéro.

## Prolongement

Dans un réseau multicouche, on empile plusieurs transformations et non-linéarités. Mais chaque couche linéaire conserve cette idée : projeter une représentation selon des poids, puis la déplacer avec un biais.
