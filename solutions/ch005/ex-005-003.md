# EX-005-003 - Vérifier XOR

## Énoncé

Essayez de tracer une droite qui sépare les points XOR positifs `(0,1)` et `(1,0)` des points négatifs `(0,0)` et `(1,1)`. Expliquez pourquoi cela échoue.

## Ce que l'exercice vérifie

L'exercice vérifie la limite classique du perceptron simple : il ne peut séparer que des classes linéairement séparables dans l'espace d'entrée original.

XOR est petit, mais il est redoutable pédagogiquement. Il montre qu'une frontière linéaire unique ne suffit pas toujours.

## Solution détaillée

Les points sont :

```text
classe 0 : (0,0), (1,1)
classe 1 : (0,1), (1,0)
```

Les points positifs sont sur une diagonale, et les points négatifs sur l'autre diagonale.

Une droite coupe le plan en deux régions. Pour réussir, elle devrait placer les deux points positifs du même côté et les deux points négatifs de l'autre côté.

Le problème est que les classes sont alternées autour du carré :

```text
(0,1) positif     (1,1) négatif

(0,0) négatif     (1,0) positif
```

Si on trace une droite pour isoler `(0,1)` avec `(1,0)`, on finit par prendre aussi un point négatif, ou par rejeter un point positif. Les deux positifs ne forment pas un demi-plan commun qui exclut les deux négatifs.

Autrement dit, il n'existe pas de poids `w1`, `w2` et de biais `b` tels que :

```text
w1*0 + w2*1 + b >= 0
w1*1 + w2*0 + b >= 0
w1*0 + w2*0 + b < 0
w1*1 + w2*1 + b < 0
```

Regardons les contraintes :

```text
w2 + b >= 0
w1 + b >= 0
b < 0
w1 + w2 + b < 0
```

Des deux premières :

```text
w1 >= -b
w2 >= -b
```

Donc :

```text
w1 + w2 >= -2b
```

Comme `b < 0`, alors `-b > 0`, et `-2b` est positif. Il devient impossible de satisfaire en même temps `w1 + w2 + b < 0` dans les conditions imposées. Le système de contraintes se contredit.

## Points importants

- XOR n'est pas linéairement séparable.
- Un perceptron simple produit une seule frontière linéaire.
- Une droite ne peut pas séparer deux diagonales alternées.
- La limite vient de l'architecture, pas d'un mauvais entraînement.

## Prolongement

Une couche cachée avec une non-linéarité peut transformer l'espace d'entrée. Après transformation, les points XOR peuvent devenir séparables par une couche de sortie linéaire. C'est l'une des raisons historiques pour lesquelles les réseaux multicouches deviennent nécessaires.
