# EX-005-001 - Calculer une prédiction

## Énoncé

Avec `w = [2, -1]`, `b = -0.5` et `x = [1, 1]`, calculez `z = w · x + b`, puis la sortie d'une fonction seuil.

## Ce que l'exercice vérifie

L'exercice vérifie la mécanique minimale d'un perceptron : un produit pondéré, un biais, puis une décision par seuil. C'est volontairement petit, parce que beaucoup de modèles plus gros gardent cette logique sous une forme plus riche.

## Solution détaillée

On calcule d'abord le score linéaire :

```text
z = w · x + b
```

Avec :

```text
w = [2, -1]
x = [1, 1]
b = -0.5
```

Le produit scalaire vaut :

```text
w · x = 2*1 + (-1)*1
      = 2 - 1
      = 1
```

On ajoute le biais :

```text
z = 1 + (-0.5)
  = 0.5
```

Si la fonction seuil est définie ainsi :

```text
sortie = 1 si z >= 0
sortie = 0 sinon
```

alors :

```text
z = 0.5 >= 0
```

La sortie vaut donc :

```text
1
```

La lecture intuitive est simple : la première feature pousse le score vers le positif avec un poids `2`, la deuxième le réduit avec un poids `-1`, puis le biais décale la décision de `-0.5`. Ici, le signal positif reste assez fort pour passer le seuil.

## Points importants

- Le perceptron calcule d'abord un score, pas directement une classe.
- Les poids déterminent l'influence des features.
- Le biais décale la frontière de décision.
- La fonction seuil transforme un score continu en décision discrète.
- Un calcul correct ne dit pas que le modèle est bon. Il dit seulement comment il décide sur cet exemple.

## Prolongement

On peut tester la sensibilité à l'entrée. Si `x = [0, 1]`, alors :

```text
z = 2*0 + (-1)*1 - 0.5 = -1.5
```

La sortie devient `0`. Une seule feature différente change la décision, ce qui montre bien le rôle des poids.
