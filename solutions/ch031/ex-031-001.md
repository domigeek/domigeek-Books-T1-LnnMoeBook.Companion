# EX-031-001 - Construire un MiniRAG sur dix documents jouets

## Énoncé

Prenez dix courts documents sur un domaine technique simple. Définissez une requête, un mécanisme de récupération, un assemblage de contexte et une réponse avec sources.

## Ce que l'exercice vérifie

L'exercice vérifie la mécanique RAG minimale : récupérer avant de générer, puis citer ce qui supporte la réponse.

## Solution détaillée

Domaine : exploitation d'une API.

Documents jouets :

```text
D1: L'API impose une limite de 100 requêtes par minute.
D2: Une réponse 429 indique un dépassement de limite.
D3: Les tokens expirent après 60 minutes.
D4: Le retry doit utiliser un backoff exponentiel.
D5: Les erreurs 500 peuvent être retentées.
D6: Les erreurs 400 ne doivent pas être retentées sans correction.
D7: Le header X-Request-Id facilite le diagnostic.
D8: Les webhooks sont signés avec HMAC.
D9: Les clés API doivent être stockées dans un coffre.
D10: Le timeout recommandé est 10 secondes.
```

Requête :

```text
Pourquoi mon client reçoit-il des 429 et que dois-je faire ?
```

Récupération simple :

- recherche lexicale sur `429`, `limite`, `requêtes` ;
- top-3 : `D2`, `D1`, `D4`.

Assemblage de contexte :

```text
[D2] Une réponse 429 indique un dépassement de limite.
[D1] L'API impose une limite de 100 requêtes par minute.
[D4] Le retry doit utiliser un backoff exponentiel.
```

Réponse :

> Le code 429 indique probablement que le client dépasse la limite d'appel. La limite documentée est de 100 requêtes par minute. Il faut réduire le débit côté client, ajouter un backoff exponentiel lors des retries et surveiller le nombre de requêtes envoyées par minute. Sources : D1, D2, D4.

## Points importants

- La récupération doit être explicite.
- Le contexte doit contenir les sources.
- La réponse doit être supportée par les documents.
- Une réponse sans source est moins vérifiable.
- RAG ne garantit pas la vérité si les documents récupérés sont mauvais.

## Prolongement

Une version plus robuste ajouterait reranking, vérification de fraîcheur, permissions et refus de répondre si aucune source solide n'est récupérée.
