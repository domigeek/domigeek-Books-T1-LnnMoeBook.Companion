# EX-004-004 - Euler à la main

## Énoncé

Avec Euler, calculez trois pas pour `dh(t) / dt = -h(t)`, `h(0) = 1` et `dt = 0.1`.

## Ce que l'exercice vérifie

L'exercice vérifie la méthode d'Euler explicite. Le but n'est pas de faire du calcul numérique avancé. Le but est de comprendre comment une équation continue devient une mise à jour discrète.

## Solution détaillée

L'équation différentielle est :

```text
dh(t) / dt = -h(t)
```

La méthode d'Euler explicite utilise :

```text
h_{n+1} = h_n + dt * f(h_n)
```

Ici :

```text
f(h_n) = -h_n
dt = 0.1
h_0 = 1
```

Donc :

```text
h_{n+1} = h_n + 0.1 * (-h_n)
        = h_n - 0.1h_n
        = 0.9h_n
```

Chaque pas multiplie donc l'état par `0.9`.

### Premier pas

```text
h_1 = 0.9 * h_0
    = 0.9 * 1
    = 0.9
```

### Deuxième pas

```text
h_2 = 0.9 * h_1
    = 0.9 * 0.9
    = 0.81
```

### Troisième pas

```text
h_3 = 0.9 * h_2
    = 0.9 * 0.81
    = 0.729
```

Résultat :

```text
h_1 = 0.9
h_2 = 0.81
h_3 = 0.729
```

### Comparaison intuitive

La solution exacte de l'équation est :

```text
h(t) = exp(-t)
```

Après trois pas avec `dt = 0.1`, on est à :

```text
t = 0.3
```

La solution exacte vaut :

```text
exp(-0.3) ≈ 0.7408
```

Euler donne :

```text
0.729
```

Ce n'est pas exact, mais c'est proche pour ce petit pas. Si `dt` était plus grand, l'erreur augmenterait.

## Points importants

- Euler remplace une dynamique continue par une mise à jour discrète.
- Ici, chaque pas multiplie l'état par `0.9`.
- Les trois valeurs sont `0.9`, `0.81`, `0.729`.
- Le pas `dt` influence directement l'erreur numérique.
- Un solveur n'est pas un détail invisible : il fait partie du comportement du modèle continu.

## Prolongement

Dans les Neural ODE, CT-RNN, LTC et architectures continues, le solveur numérique peut influencer coût, stabilité et précision. C'est une raison importante de ne pas traiter le temps continu comme un simple slogan. Le modèle définit une dynamique, mais le solveur décide comment cette dynamique est approximée sur machine.
