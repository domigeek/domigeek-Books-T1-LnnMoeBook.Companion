# EX-004-002 - Lire une équation de décroissance

## Énoncé

Pour `dh(t) / dt = -0.5 * h(t)`, expliquez ce qui se passe si `h(0) = 10`, puis si `h(0) = -4`.

## Ce que l'exercice vérifie

L'exercice vérifie la lecture qualitative d'une équation différentielle simple. Avant de résoudre exactement une équation, il faut savoir lire son comportement.

Ici, la dérivée dépend de l'état lui-même.

## Solution détaillée

L'équation est :

```text
dh(t) / dt = -0.5 * h(t)
```

Elle dit que la vitesse de changement de `h` est proportionnelle à `h`, mais avec un signe négatif.

### Cas 1 : `h(0) = 10`

Au départ :

```text
h = 10
dh/dt = -0.5 * 10 = -5
```

La dérivée est négative. Donc `h` diminue.

Quand `h` devient plus petit, par exemple `h = 4`, la dérivée vaut :

```text
dh/dt = -0.5 * 4 = -2
```

La valeur continue de diminuer, mais moins vite. Plus `h` approche de zéro, plus la dérivée approche de zéro.

Le comportement est donc :

```text
10 -> diminue -> se rapproche de 0
```

sans traverser brutalement zéro dans la solution continue idéale.

### Cas 2 : `h(0) = -4`

Au départ :

```text
h = -4
dh/dt = -0.5 * (-4) = 2
```

La dérivée est positive. Donc `h` augmente.

Mais "augmente" ici veut dire qu'il devient moins négatif :

```text
-4 -> -3 -> -2 -> -1 -> se rapproche de 0
```

Quand `h = -1`, la dérivée vaut :

```text
dh/dt = -0.5 * (-1) = 0.5
```

La remontée continue, mais ralentit.

### Lecture générale

Dans les deux cas, `h = 0` est un point fixe, car :

```text
dh/dt = -0.5 * 0 = 0
```

Si l'état est positif, la dérivée est négative et le ramène vers zéro.

Si l'état est négatif, la dérivée est positive et le ramène aussi vers zéro.

On peut donc dire que zéro est un point fixe stable.

La solution exacte a la forme :

```text
h(t) = h(0) * exp(-0.5 t)
```

Mais l'intuition importante est déjà visible sans résoudre : le signe de la dérivée pousse toujours l'état vers zéro.

## Points importants

- Si `h > 0`, alors `dh/dt < 0`.
- Si `h < 0`, alors `dh/dt > 0`.
- Dans les deux cas, l'état se rapproche de zéro.
- Le point `h = 0` est un point fixe.
- Ce point fixe est stable.

## Prolongement

Cette équation ressemble à un mécanisme d'oubli ou de relaxation. Dans un modèle continu, un état peut naturellement décroître s'il n'est pas alimenté. Mais il faut rester prudent : un vrai réseau neuronal continu ajoute des entrées, des paramètres, des non-linéarités et des solveurs numériques. Cette équation est une brique d'intuition, pas un modèle complet.
