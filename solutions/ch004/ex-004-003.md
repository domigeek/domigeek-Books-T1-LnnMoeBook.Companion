# EX-004-003 - Point fixe stable ou instable

## Énoncé

Pour `dh(t) / dt = -2 * h(t)` et `dh(t) / dt = 3 * h(t)`, identifiez le point fixe `h* = 0` et dites s'il est stable ou instable.

## Ce que l'exercice vérifie

L'exercice vérifie la lecture de stabilité autour d'un point fixe. C'est une notion centrale dans les systèmes dynamiques : il ne suffit pas de savoir où l'état peut rester immobile. Il faut savoir ce qui arrive quand on le perturbe un peu.

## Solution détaillée

Un point fixe est une valeur `h*` pour laquelle :

```text
dh/dt = 0
```

Dans les deux équations, `h = 0` annule la dérivée.

### Premier système

```text
dh(t) / dt = -2 * h(t)
```

Si `h` est positif :

```text
h > 0
dh/dt = -2h < 0
```

L'état diminue. Il revient vers zéro.

Si `h` est négatif :

```text
h < 0
dh/dt = -2h > 0
```

L'état augmente. Comme il était négatif, il remonte vers zéro.

Des deux côtés, la dynamique ramène l'état vers le point fixe. Donc :

```text
h* = 0 est stable
```

La solution exacte est :

```text
h(t) = h(0) * exp(-2t)
```

Le facteur `exp(-2t)` décroît quand `t` augmente.

### Deuxième système

```text
dh(t) / dt = 3 * h(t)
```

Si `h` est positif :

```text
h > 0
dh/dt = 3h > 0
```

L'état augmente. Il s'éloigne de zéro.

Si `h` est négatif :

```text
h < 0
dh/dt = 3h < 0
```

L'état diminue. Comme il était déjà négatif, il devient encore plus négatif. Il s'éloigne aussi de zéro.

Des deux côtés, une petite perturbation est amplifiée. Donc :

```text
h* = 0 est instable
```

La solution exacte est :

```text
h(t) = h(0) * exp(3t)
```

Le facteur `exp(3t)` augmente avec le temps.

## Points importants

- Les deux systèmes ont `h* = 0` comme point fixe.
- Dans `dh/dt = -2h`, zéro est stable.
- Dans `dh/dt = 3h`, zéro est instable.
- Le signe du coefficient devant `h` est déterminant dans ce cas linéaire.
- Stable ne veut pas dire immobile partout. Cela veut dire que les petites perturbations reviennent vers le point fixe.

## Prolongement

Dans un réseau neuronal continu, les dynamiques sont souvent non linéaires et multidimensionnelles. La stabilité ne se lit plus toujours avec un simple signe. On doit parfois regarder des Jacobiennes, des valeurs propres, des bornes ou des simulations. Mais l'intuition de base reste la même : une dynamique stable amortit certaines perturbations, une dynamique instable les amplifie.
