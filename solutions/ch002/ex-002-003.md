# EX-002-003 - Distance euclidienne et similarité cosinus

## Énoncé

Comparez distance euclidienne et similarité cosinus entre `a = [1, 0]`, `b = [10, 0]` et `c = [0, 1]`.

## Ce que l'exercice vérifie

L'exercice vérifie la différence entre deux notions qu'on confond trop souvent :

- la distance euclidienne mesure un écart géométrique en longueur ;
- la similarité cosinus mesure surtout l'alignement de direction.

Dans les systèmes d'embeddings, cette distinction est importante. Deux vecteurs peuvent pointer dans la même direction tout en ayant des normes très différentes.

## Solution détaillée

On définit :

```text
a = [1, 0]
b = [10, 0]
c = [0, 1]
```

### Distance euclidienne

La distance euclidienne entre deux vecteurs `u` et `v` est :

```text
d(u, v) = sqrt(sum_i (u_i - v_i)^2)
```

Entre `a` et `b` :

```text
d(a, b) = sqrt((1 - 10)^2 + (0 - 0)^2)
        = sqrt(81)
        = 9
```

Entre `a` et `c` :

```text
d(a, c) = sqrt((1 - 0)^2 + (0 - 1)^2)
        = sqrt(1 + 1)
        = sqrt(2)
        ≈ 1.414
```

Avec la distance euclidienne, `a` est donc beaucoup plus proche de `c` que de `b`.

### Similarité cosinus

La similarité cosinus est :

```text
cos(u, v) = (u · v) / (||u|| ||v||)
```

Entre `a` et `b` :

```text
a · b = 1*10 + 0*0 = 10
||a|| = 1
||b|| = 10
cos(a, b) = 10 / (1 * 10) = 1
```

Les vecteurs pointent exactement dans la même direction.

Entre `a` et `c` :

```text
a · c = 1*0 + 0*1 = 0
||a|| = 1
||c|| = 1
cos(a, c) = 0 / (1 * 1) = 0
```

Les vecteurs sont orthogonaux.

### Comparaison

| Paire | Distance euclidienne | Similarité cosinus | Lecture |
|---|---:|---:|---|
| `a`, `b` | `9` | `1` | Même direction, norme très différente |
| `a`, `c` | `sqrt(2)` | `0` | Distance courte, direction orthogonale |

Ce résultat surprend souvent au début. Avec la distance euclidienne, `a` paraît plus proche de `c`. Avec le cosinus, `a` est parfaitement aligné avec `b`.

Les deux mesures ne répondent pas à la même question.

## Exemple C# minimal

```csharp
static double Euclidean(double[] u, double[] v)
{
    var sum = 0.0;
    for (var i = 0; i < u.Length; i++)
        sum += Math.Pow(u[i] - v[i], 2);
    return Math.Sqrt(sum);
}

static double Cosine(double[] u, double[] v)
{
    var dot = 0.0;
    var nu = 0.0;
    var nv = 0.0;

    for (var i = 0; i < u.Length; i++)
    {
        dot += u[i] * v[i];
        nu += u[i] * u[i];
        nv += v[i] * v[i];
    }

    return dot / (Math.Sqrt(nu) * Math.Sqrt(nv));
}
```

## Points importants

- La distance euclidienne est sensible à la norme.
- La similarité cosinus normalise par la norme et regarde surtout la direction.
- Dans un espace d'embeddings, le choix de métrique change les voisins obtenus.
- Aucun choix n'est universel. Il dépend de ce que la norme signifie dans le modèle.

## Prolongement

Si la norme encode une information utile, par exemple une confiance, une intensité ou une fréquence, ignorer la norme peut faire perdre du signal. Si la norme est surtout un artefact d'entraînement, la similarité cosinus peut être plus stable. La bonne question est donc : que représente la norme dans ce système ?
