# EX-002-002 - Lire une shape de modèle

## Énoncé

Pour le tenseur `H : (16, 200, 768)`, proposez deux interprétations possibles et expliquez ce que représenterait `H[0, 10, :]`.

## Ce que l'exercice vérifie

L'exercice vérifie la capacité à lire une shape comme un contrat de données. Une shape n'est pas seulement une suite de nombres. Chaque axe a une responsabilité.

Ici, `H : (16, 200, 768)` peut représenter plusieurs choses selon le contexte.

## Solution détaillée

Une interprétation classique en NLP ou en modèles de séquence est :

```text
H : (batch, tokens, features)
H : (16, 200, 768)
```

Dans cette lecture :

- `16` est le nombre d'exemples dans le batch ;
- `200` est la longueur de séquence, par exemple 200 tokens ;
- `768` est la dimension de représentation de chaque token.

Alors :

```text
H[0, 10, :]
```

désigne le vecteur de dimension `768` du token à la position `10` dans le premier exemple du batch.

Attention : selon la convention d'indexation, la position `10` est généralement la onzième position si l'indexation commence à zéro.

Une deuxième interprétation possible dans une série temporelle multivariée est :

```text
H : (batch, time_steps, latent_features)
H : (16, 200, 768)
```

Dans cette lecture :

- `16` est le nombre de trajectoires ou fenêtres temporelles ;
- `200` est le nombre de pas de temps observés ;
- `768` est la représentation latente produite par un encodeur.

Alors `H[0, 10, :]` représente l'état latent complet au pas de temps `10` pour la première trajectoire.

La différence entre les deux interprétations n'est pas dans la shape. Elle est dans la sémantique :

| Axe | Interprétation NLP | Interprétation série temporelle |
|---|---|---|
| 0 | exemple du batch | trajectoire ou fenêtre |
| 1 | position de token | pas de temps |
| 2 | embedding du token | état latent ou features encodées |

Dans les deux cas, `H[0, 10, :]` est une tranche vectorielle de taille `768`.

Ce vecteur peut ensuite être :

- projeté par une matrice ;
- envoyé à une couche feed-forward ;
- comparé par attention ;
- résumé dans un pooling ;
- utilisé comme état d'entrée pour une autre architecture.

Le piège fréquent est de supposer que `(16, 200, 768)` signifie toujours la même chose. Ce n'est pas vrai. Certains frameworks ou modèles utilisent aussi :

```text
(time, batch, features)
```

ou :

```text
(batch, features, time)
```

Sans convention claire, le même tenseur peut être correct dans le type, mais faux dans le sens.

## Points importants

- `H[0, 10, :]` est un vecteur de taille `768`.
- La shape seule ne suffit pas. Il faut nommer les axes.
- Le premier axe est souvent le batch, mais ce n'est pas une loi universelle.
- L'axe de séquence peut représenter des tokens, des pas de temps, des événements ou des frames.
- Le dernier axe représente souvent les features ou la dimension latente.

## Prolongement

Dans un système modulaire, il est utile de documenter les tenseurs comme ceci :

```text
H:
  shape: (batch, sequence, hidden)
  batch: nombre d'exemples
  sequence: tokens après padding/troncature
  hidden: dimension latente du modèle
```

Ce genre de contrat évite beaucoup de temps perdu. Un modèle ne plante pas toujours quand les axes sont inversés. Parfois il apprend simplement n'importe quoi, très sérieusement, pendant plusieurs heures.
