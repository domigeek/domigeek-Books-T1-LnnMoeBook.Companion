# EX-015-001 - Lire l'équation CT-RNN

## Énoncé

Expliquez en prose `dh(t)/dt = (-h(t) + phi(W_h*h(t) + W_x*x(t) + b)) / tau`.

## Ce que l'exercice vérifie

L'exercice vérifie la lecture d'un RNN en temps continu. L'état ne saute pas directement vers une nouvelle valeur : il évolue selon une dérivée.

## Solution détaillée

L'équation est :

```text
dh(t)/dt = (-h(t) + phi(W_h*h(t) + W_x*x(t) + b)) / tau
```

Le terme `-h(t)` représente une fuite ou relaxation. Si rien ne pousse l'état autrement, il tend à revenir ou à se réduire.

Le terme :

```text
phi(W_h*h(t) + W_x*x(t) + b)
```

produit une cible ou contribution non linéaire à partir de l'état courant et de l'entrée courante.

`W_h` transforme l'état courant. `W_x` transforme l'entrée. `b` décale le calcul. `phi` ajoute une non-linéarité.

La constante `tau` contrôle la vitesse d'évolution. Si `tau` est grand, le changement est plus lent. Si `tau` est petit, l'état peut évoluer plus rapidement.

Lecture simple :

```text
l'état évolue vers une cible non linéaire,
avec une vitesse contrôlée par tau
```

## Points importants

- `-h(t)` agit comme une fuite.
- `phi(...)` calcule une contribution non linéaire.
- `W_h` utilise l'état courant.
- `W_x` utilise l'entrée.
- `tau` contrôle l'échelle temporelle.

## Prolongement

Un CT-RNN prépare l'intuition des LTC : l'état suit une dynamique continue, mais les LTC rendent certaines constantes temporelles ou effets dynamiques plus dépendants du contexte.
