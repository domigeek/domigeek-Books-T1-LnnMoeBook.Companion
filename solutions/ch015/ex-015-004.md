# EX-015-004 - Simulation Euler

## Énoncé

Écrivez une boucle Euler minimale pour simuler un CT-RNN.

## Ce que l'exercice vérifie

L'exercice vérifie comment une dynamique continue devient une simulation discrète. Même si le modèle est écrit avec une dérivée, la machine avance par pas numériques.

## Solution détaillée

Une boucle Euler minimale suit ce schéma :

```text
h = h0
t = t0

tant que t < t_final:
    dh = f(h, x(t), t)
    h = h + dt * dh
    t = t + dt
```

Pour un CT-RNN, `f` peut être :

```text
f(h, x, t) = (-h + phi(W_h*h + W_x*x + b)) / tau
```

Pseudo-code :

```text
h = h0
t = 0

for step in 1..N:
    x = input_at(t)
    pre = W_h*h + W_x*x + b
    target = phi(pre)
    dh = (-h + target) / tau
    h = h + dt * dh
    t = t + dt
```

Le choix de `dt` est important. Si `dt` est trop grand, la simulation peut être imprécise ou instable. Si `dt` est très petit, elle peut être coûteuse.

## Points importants

- Euler calcule une dérivée puis avance l'état.
- La mise à jour est `h = h + dt * dh`.
- `dt` influence précision et stabilité.
- Même un modèle continu est simulé numériquement.
- Le choix de `input_at(t)` fait partie du modèle effectif.
