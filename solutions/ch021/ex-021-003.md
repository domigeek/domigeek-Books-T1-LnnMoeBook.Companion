# EX-021-003 - Gate ou routeur

## Énoncé

Quelle différence faites-vous entre un gate network historique et un routeur MoE moderne ?

## Ce que l'exercice vérifie

L'exercice vérifie l'évolution du vocabulaire. Gate et routeur sont proches, mais les MoE modernes ajoutent des responsabilités système.

## Solution détaillée

Dans les Mixture-of-Experts historiques, le gate network produit souvent des poids de combinaison. Chaque expert peut produire une sortie, puis le gate pondère ces sorties.

Schéma :

```text
entrée -> experts locaux -> sorties pondérées par gate -> sortie finale
```

Dans un MoE moderne sparse, le routeur peut aller plus loin. Il ne se contente pas de pondérer. Il sélectionne un sous-ensemble d'experts actifs, par exemple top-1 ou top-2, puis déclenche seulement ces experts.

Schéma :

```text
token -> routeur -> experts sélectionnés -> dispatch -> recombinaison
```

Le routeur moderne doit donc gérer des contraintes supplémentaires :

- top-k ;
- capacité par expert ;
- tokens débordés ;
- équilibrage de charge ;
- communication entre devices ;
- métriques d'utilisation ;
- stabilité du routage.

Le gate historique est surtout un mécanisme de combinaison. Le routeur moderne est à la fois un mécanisme de sélection, une source de sparsité et un composant d'infrastructure.

## Points importants

- Le gate historique pondère des experts.
- Le routeur moderne sélectionne souvent des experts actifs.
- Le routage sparse réduit le calcul actif.
- La capacité et le load balancing deviennent centraux.
- Le routeur moderne crée aussi des contraintes matérielles.

## Prolongement

Dans un petit prototype, la différence peut sembler subtile. À grande échelle, elle devient majeure : le routeur décide aussi où vont les données, combien de mémoire est utilisée et quels devices sont sollicités.
