# EX-024-002 - Paramètres totaux et actifs

## Énoncé

Un modèle possède 32 experts de 50 millions de paramètres chacun. Le routeur active 2 experts par token. Calculez les paramètres experts totaux et les paramètres experts actifs par token.

## Ce que l'exercice vérifie

L'exercice vérifie la différence entre capacité stockée et calcul actif.

## Solution détaillée

Nombre d'experts :

```text
N = 32
```

Paramètres par expert :

```text
P = 50 000 000
```

Paramètres experts totaux :

```text
N * P = 32 * 50 000 000
      = 1 600 000 000
```

Donc :

```text
1,6 milliard de paramètres experts
```

Le routeur active 2 experts par token :

```text
k = 2
```

Paramètres experts actifs par token :

```text
k * P = 2 * 50 000 000
      = 100 000 000
```

Donc environ :

```text
100 millions de paramètres experts actifs par token
```

Attention : ce calcul ignore :

- routeur ;
- couches partagées ;
- embeddings ;
- attention ;
- communication ;
- mémoire totale ;
- buffers ;
- KV cache ;
- overhead de dispatch.

## Points importants

- Total experts : `1,6B`.
- Actif par token : `100M`.
- Le modèle doit stocker plus que ce qu'il active.
- Le coût actif n'est pas le coût système complet.
- Le calcul `k * P` est utile, mais incomplet.

## Prolongement

Cette distinction explique pourquoi un MoE peut être puissant mais exigeant en mémoire. Même si peu d'experts sont actifs, les autres doivent être disponibles quelque part.
