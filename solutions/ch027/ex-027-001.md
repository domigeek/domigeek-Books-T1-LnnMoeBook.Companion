# EX-027-001 - Routage top-2 synthétique

## Énoncé

Créez une matrice de logits `tokens x experts`, sélectionnez les deux experts les plus probables pour chaque token, appliquez une softmax sur ces deux valeurs, puis affichez une matrice token-expert des poids non nuls.

## Ce que l'exercice vérifie

L'exercice vérifie la mécanique top-2 utilisée par des MoE modernes : deux experts actifs, poids normalisés, matrice sparse lisible.

## Solution détaillée

Exemple :

```text
logits =
token 0 : [3.0, 1.0, 2.0, 0.0]
token 1 : [0.2, 2.5, 0.1, 1.8]
token 2 : [1.1, 1.0, 4.0, 0.5]
```

Top-2 :

```text
token 0 -> experts 0 et 2
token 1 -> experts 1 et 3
token 2 -> experts 2 et 0
```

On applique une softmax seulement sur les deux logits retenus.

Matrice sparse attendue, qualitativement :

```text
          e0    e1    e2    e3
token 0  >0    0     >0    0
token 1  0     >0    0     >0
token 2  >0    0     >0    0
```

Pour chaque ligne :

```text
somme des poids non nuls = 1
```

Tests :

- exactement deux experts non nuls par token ;
- indices corrects ;
- poids normalisés ;
- shape finale `(tokens, experts)` ;
- pas de poids sur expert non retenu.

## Points importants

- Top-2 garde deux experts par token.
- Les poids doivent être recalculés sur les experts retenus.
- La matrice finale est sparse.
- Chaque ligne doit sommer à `1`.
- La heatmap aide à diagnostiquer le routage.

## Prolongement

Dans un modèle réel, on ajoute capacité, load balancing, batch distribué et métriques par expert. Le petit test reste utile pour verrouiller la logique.
