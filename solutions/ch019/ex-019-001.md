# EX-019-001 - Brique ou modèle de fondation

## Énoncé

Expliquez la différence entre une cellule LTC, un réseau LTC et un modèle de fondation liquide.

## Ce que l'exercice vérifie

L'exercice vérifie les niveaux d'échelle. Une cellule, un réseau et un modèle de fondation ne désignent pas la même chose.

## Solution détaillée

Une cellule LTC est une unité de calcul dynamique. Elle définit comment un état évolue selon une équation et des paramètres.

Un réseau LTC organise plusieurs cellules ou couches pour traiter une tâche. Il ajoute :

- connectivité ;
- entrées et sorties ;
- entraînement ;
- fonction de perte ;
- solveur ;
- intégration dans un pipeline.

Un modèle de fondation liquide est un objet beaucoup plus large. Il peut inclure :

- architecture complète ;
- préentraînement massif ;
- données variées ;
- post-entraînement ;
- évaluation large ;
- outillage d'inférence ;
- quantification ;
- déploiement ;
- documentation ;
- limites d'usage.

Confondre les trois mène à des affirmations trop rapides. Montrer une cellule intéressante ne prouve pas qu'on a un modèle de fondation. Entraîner un petit réseau LTC ne prouve pas non plus qu'on a une base générale.

## Points importants

- Une cellule est une unité.
- Un réseau assemble des unités pour une tâche.
- Un modèle de fondation implique échelle, données, entraînement, évaluation et outillage.
- Les propriétés ne se transfèrent pas automatiquement d'un niveau à l'autre.
- Il faut préciser le niveau dont on parle.

## Prolongement

Cette distinction vaut aussi pour Transformers, SSM et MoE. Une brique architecturale n'est pas un produit complet ni une preuve de généralité.
