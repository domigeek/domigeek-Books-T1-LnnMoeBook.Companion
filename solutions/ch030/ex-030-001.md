# EX-030-001 - Routeur piloté par état temporel

## Énoncé

Concevez une architecture où un état temporel continu pilote le routage vers cinq experts spécialisés.

## Ce que l'exercice vérifie

L'exercice vérifie la capacité à séparer l'orchestrateur, l'état dynamique, le routage et les experts. Le LNN ne doit pas devenir une boîte magique : il fournit un état utile au routeur.

## Solution détaillée

Une architecture minimale :

```text
EventEnvelope
  -> encodeur d'entrée
  -> état temporel continu h(t)
  -> routeur MoE
  -> cinq experts spécialisés
  -> agrégateur
  -> sortie + trace
```

Les cinq experts pourraient être :

| Expert | Rôle |
|---|---|
| `ExpertIntent` | classifier l'intention ou le type de demande |
| `ExpertMemory` | décider si une récupération mémoire est utile |
| `ExpertCode` | traiter les tâches de code ou configuration |
| `ExpertOps` | traiter logs, incidents, métriques et exploitation |
| `ExpertSafety` | vérifier contraintes, permissions et risques |

L'état continu `h(t)` reçoit les événements avec leur délai réel. Il ne choisit pas seul la réponse finale. Il fournit au routeur une représentation du contexte dynamique :

```text
route_scores = Router(h(t), x_t, contraintes)
```

Le routeur produit ensuite des scores, un top-k et des poids. Les experts ont un contrat stable :

```text
input: contexte, événement, état résumé, contraintes
output: proposition, confiance, coût, traces
```

Métriques :

- distribution de routage par expert ;
- latence par expert ;
- coût par décision ;
- taux de fallback ;
- qualité par type de tâche ;
- stabilité de l'état ;
- dérive de routage dans le temps.

## Points importants

- Le LNN maintient un état dynamique.
- Le routeur utilise cet état pour classer ou pondérer les experts.
- Les experts gardent un contrat explicite.
- Les contraintes système restent hors du LNN.
- L'observabilité doit couvrir état, routage, coût et qualité.

## Prolongement

La baseline minimale est un routeur statique ou un classifieur discret. Le routage dynamique n'est justifié que s'il améliore qualité, robustesse ou coût dans des scénarios rejouables.
