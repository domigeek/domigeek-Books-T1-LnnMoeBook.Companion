# EX-022-005 - Interpréter sans anthropomorphiser

## Énoncé

Vous observez qu'un expert reçoit souvent des entrées contenant du code. Que pouvez-vous conclure, et que devez-vous encore vérifier ?

## Ce que l'exercice vérifie

L'exercice vérifie la séparation entre observation de routage et interprétation sémantique.

## Solution détaillée

Conclusion prudente :

```text
cet expert est souvent routé pour des entrées contenant du code dans les données observées.
```

C'est tout.

On ne peut pas conclure immédiatement que :

- l'expert "comprend" le code ;
- il est l'expert code du modèle ;
- il est nécessaire pour toutes les tâches de code ;
- sa spécialisation est stable ;
- il fonctionne mieux qu'un autre expert sur le code.

Il faut vérifier :

- performance sur tâches de code quand l'expert est activé ;
- performance si on masque cet expert ;
- stabilité sur plusieurs couches ;
- stabilité sur plusieurs seeds ;
- routage sur code, pseudo-code, logs, JSON, texte technique ;
- confusion avec motifs syntaxiques comme accolades ou indentation ;
- comparaison avec un modèle dense.

Il faut aussi regarder si l'expert reçoit du code parce qu'il est bon, ou parce que le routeur a appris une corrélation pratique mais fragile.

## Points importants

- On peut conclure à une régularité observée.
- On ne peut pas conclure à une spécialisation humaine fixe.
- Les ablations sont indispensables.
- La couche et le contexte comptent.
- L'interprétation doit rester mesurable.

## Prolongement

La bonne formulation est : "dans ce protocole, cet expert est fortement associé à des entrées contenant du code". Le reste demande des preuves.
