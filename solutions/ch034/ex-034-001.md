# EX-034-001 - Inventaire de gouvernance

## Énoncé

Prenez un assistant RAG avec un modèle, un index vectoriel, trois outils et une mémoire persistante. Listez tous les artefacts qui doivent être versionnés.

## Ce que l'exercice vérifie

L'exercice vérifie que gouverner un système IA demande de versionner plus que le modèle.

## Solution détaillée

Artefacts à versionner :

```text
modèle
tokenizer
prompts système
prompts de tâche
politiques de sécurité
politiques de mémoire
corpus documentaire
chunks
embeddings
index vectoriel
reranker
schémas d'outils
versions des outils
configuration d'orchestration
mémoire persistante
politiques de permissions
métriques
jeux d'évaluation
runbooks
```

Pour les trois outils :

- nom ;
- version ;
- schéma d'entrée ;
- schéma de sortie ;
- permissions ;
- limites ;
- coûts ;
- erreurs possibles.

Pour la mémoire persistante :

- schéma ;
- version des entrées ;
- provenance ;
- statut ;
- historique des modifications ;
- politique d'oubli.

Sans cet inventaire, un incident devient presque impossible à expliquer. On ne sait plus si la réponse a changé à cause du modèle, du corpus, de l'index, du prompt, d'un outil ou d'une mémoire.

## Points importants

- Le modèle n'est qu'un artefact parmi d'autres.
- Corpus, index et embeddings doivent être versionnés ensemble.
- Les prompts sont du comportement système.
- Les outils doivent avoir des contrats versionnés.
- Les runbooks font partie de l'exploitation.

## Prolongement

La gouvernance n'est pas une couche administrative après coup. C'est ce qui permet de comprendre, corriger et reproduire un comportement.
