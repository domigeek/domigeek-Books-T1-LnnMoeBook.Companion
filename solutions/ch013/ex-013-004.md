# EX-013-004 - Modèle continu

## Énoncé

Expliquez la différence entre `h_{t+1} = f(h_t, x_t)` et `dh(t)/dt = f(h(t), x(t), t)`.

## Ce que l'exercice vérifie

L'exercice vérifie la différence entre mise à jour discrète et loi d'évolution continue. Les deux parlent d'état, mais pas de la même manière.

## Solution détaillée

La première équation :

```text
h_{t+1} = f(h_t, x_t)
```

dit que l'on calcule directement le prochain état à partir de l'état courant et de l'entrée courante.

Le temps est un index :

```text
t = 0, 1, 2, ...
```

On avance par sauts. Cette formulation convient bien quand les observations sont régulières ou quand on accepte de les traiter comme une séquence de pas équivalents.

La deuxième équation :

```text
dh(t)/dt = f(h(t), x(t), t)
```

ne donne pas directement le prochain état. Elle donne la vitesse de changement de l'état au temps `t`.

Pour obtenir l'état à un temps ultérieur, il faut intégrer cette équation avec un solveur numérique.

Lecture simple :

```text
discret : voici le prochain état
continu : voici comment l'état évolue maintenant
```

La différence devient importante quand les observations sont irrégulières. Dans un modèle continu, le temps écoulé entre deux observations peut être naturellement pris en compte par l'intégration.

Mais le continu ajoute aussi du coût :

- solveur ;
- choix de pas ;
- stabilité numérique ;
- temps d'entraînement ;
- difficulté de diagnostic.

## Points importants

- La formulation discrète calcule une transition par pas.
- La formulation continue calcule une dérivée.
- Un modèle continu nécessite une intégration numérique.
- Les données irrégulières peuvent justifier le continu.
- Le continu n'est pas gratuit : il ajoute des choix numériques.

## Prolongement

Les Neural ODE, CT-RNN, LTC et CfC explorent différentes façons de définir ou approximer cette dynamique continue. Le choix doit être validé contre des modèles discrets bien préparés.
