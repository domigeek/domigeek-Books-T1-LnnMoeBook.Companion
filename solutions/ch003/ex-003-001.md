# EX-003-001 - Calculer un gradient simple

## Énoncé

Pour `L(w, b) = (w*x + b - y)^2` avec `x = 2`, `y = 5`, `w = 1` et `b = 0`, calculez la prédiction, la perte et les gradients.

## Ce que l'exercice vérifie

L'exercice vérifie la base du calcul différentiel utilisé en apprentissage supervisé : une prédiction, une erreur, une perte, puis un gradient qui indique comment ajuster les paramètres.

Ce petit exemple est volontairement simple. Il permet de voir le mécanisme sans cacher l'idée derrière un framework.

## Solution détaillée

Le modèle est :

```text
y_hat = w*x + b
```

Avec :

```text
x = 2
y = 5
w = 1
b = 0
```

La prédiction vaut :

```text
y_hat = 1*2 + 0 = 2
```

La perte est :

```text
L(w, b) = (w*x + b - y)^2
        = (2 - 5)^2
        = (-3)^2
        = 9
```

On introduit l'erreur :

```text
e = y_hat - y
```

Ici :

```text
e = 2 - 5 = -3
```

La perte devient :

```text
L = e^2
```

### Gradient par rapport à `w`

On applique la règle de chaîne.

```text
dL/de = 2e
de/dw = x
```

Donc :

```text
dL/dw = dL/de * de/dw
      = 2e*x
```

Avec les valeurs numériques :

```text
dL/dw = 2*(-3)*2 = -12
```

### Gradient par rapport à `b`

De la même manière :

```text
dL/de = 2e
de/db = 1
```

Donc :

```text
dL/db = 2e*1
      = 2*(-3)
      = -6
```

### Lecture du résultat

Les gradients sont négatifs :

```text
dL/dw = -12
dL/db = -6
```

En descente de gradient, on met à jour les paramètres dans la direction opposée au gradient :

```text
w_new = w - learning_rate * dL/dw
b_new = b - learning_rate * dL/db
```

Comme les gradients sont négatifs, `w` et `b` vont augmenter si le learning rate est positif. C'est logique : la prédiction `2` est trop basse par rapport à la cible `5`. Augmenter `w` ou `b` augmente `y_hat`.

Par exemple, avec `learning_rate = 0.1` :

```text
w_new = 1 - 0.1*(-12) = 2.2
b_new = 0 - 0.1*(-6)  = 0.6
```

Ce pas est probablement trop grand pour un exemple aussi simple, mais il illustre bien le sens de correction.

## Points importants

- La prédiction vaut `2`.
- La perte vaut `9`.
- Le gradient par rapport à `w` vaut `-12`.
- Le gradient par rapport à `b` vaut `-6`.
- Le signe du gradient indique comment la perte change si le paramètre augmente.
- La descente de gradient se déplace dans la direction opposée au gradient.

## Prolongement

Dans un réseau profond, le principe reste le même. La différence est que `w*x + b` devient une longue composition d'opérations. La backpropagation n'invente pas une autre logique : elle applique efficacement la règle de chaîne sur tout le graphe computationnel.
