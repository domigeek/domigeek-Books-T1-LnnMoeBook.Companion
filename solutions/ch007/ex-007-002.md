# EX-007-002 - Identifier le forward et le backward

## Énoncé

Pour un MLP avec deux couches cachées, listez les valeurs calculées pendant le forward et les gradients calculés pendant le backward.

## Ce que l'exercice vérifie

L'exercice vérifie la lecture du graphe computationnel. Le forward construit les valeurs. Le backward propage les gradients dans le sens inverse.

## Solution détaillée

Prenons un MLP :

```text
z1 = X @ W1 + b1
h1 = activation(z1)
z2 = h1 @ W2 + b2
h2 = activation(z2)
logits = h2 @ W3 + b3
L = loss(logits, y)
```

Pendant le forward, on calcule :

- `z1`, la pré-activation de la première couche ;
- `h1`, l'activation de la première couche ;
- `z2`, la pré-activation de la deuxième couche ;
- `h2`, l'activation de la deuxième couche ;
- `logits`, les scores de sortie ;
- `L`, la perte.

Ces valeurs ne sont pas seulement des résultats intermédiaires jetables. Certaines doivent être conservées pour le backward. Par exemple, pour dériver une activation, on a souvent besoin de sa pré-activation ou de sa sortie.

Pendant le backward, on part de :

```text
dL/dL = 1
```

Puis on remonte :

- gradient de la perte par rapport aux logits ;
- gradients de `W3`, `b3` et `h2` ;
- gradients de l'activation de la deuxième couche ;
- gradients de `W2`, `b2` et `h1` ;
- gradients de l'activation de la première couche ;
- gradients de `W1`, `b1` et éventuellement `X`.

En forme simplifiée :

```text
forward:
X -> z1 -> h1 -> z2 -> h2 -> logits -> L

backward:
L -> logits -> h2 -> z2 -> h1 -> z1 -> X
```

Les paramètres mis à jour sont :

```text
W1, b1, W2, b2, W3, b3
```

Le gradient par rapport à `X` peut être calculé, mais on ne met généralement pas à jour les entrées. Il devient utile si `X` vient d'une couche précédente ou si on analyse la sensibilité.

## Points importants

- Le forward calcule les activations et la perte.
- Le backward calcule les gradients.
- Les gradients suivent le graphe en sens inverse.
- Les valeurs du forward servent souvent au backward.
- Les paramètres sont mis à jour avec leurs gradients, pas les activations elles-mêmes.

## Prolongement

Les frameworks d'autograd automatisent ce travail, mais ils ne suppriment pas le besoin de comprendre le graphe. Quand un gradient est nul, explosif ou `NaN`, il faut savoir où regarder.
