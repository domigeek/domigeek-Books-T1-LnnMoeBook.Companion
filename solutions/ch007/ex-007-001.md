# EX-007-001 - Appliquer la règle de chaîne

## Énoncé

Avec `u = 3x` et `y = u^2`, calculez `dy/dx` en utilisant la règle de chaîne.

## Ce que l'exercice vérifie

L'exercice vérifie la base de la backpropagation : quand une valeur dépend d'une autre par plusieurs étapes, les dérivées se multiplient le long du chemin.

## Solution détaillée

On a deux relations :

```text
u = 3x
y = u^2
```

On veut :

```text
dy/dx
```

Comme `y` dépend de `u`, et `u` dépend de `x`, on applique la règle de chaîne :

```text
dy/dx = dy/du * du/dx
```

Calculons chaque terme.

Pour :

```text
y = u^2
```

la dérivée par rapport à `u` est :

```text
dy/du = 2u
```

Pour :

```text
u = 3x
```

la dérivée par rapport à `x` est :

```text
du/dx = 3
```

Donc :

```text
dy/dx = 2u * 3
      = 6u
```

Comme `u = 3x`, on peut aussi écrire :

```text
dy/dx = 6*(3x)
      = 18x
```

On peut vérifier directement :

```text
y = u^2 = (3x)^2 = 9x^2
```

La dérivée directe est :

```text
dy/dx = 18x
```

On retrouve le même résultat.

## Points importants

- La règle de chaîne multiplie les dérivées locales.
- `dy/du = 2u`.
- `du/dx = 3`.
- Le résultat est `dy/dx = 18x`.
- La backpropagation applique cette logique sur des graphes beaucoup plus grands.

## Prolongement

Dans un réseau profond, chaque couche ajoute une étape entre la perte et les paramètres. La backpropagation garde les dérivées locales et les compose efficacement. C'est le même principe que cet exercice, mais appliqué à des milliers ou milliards de paramètres.
