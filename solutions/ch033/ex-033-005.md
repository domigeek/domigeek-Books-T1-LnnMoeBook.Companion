# EX-033-005 - Système multi-agent minimal

## Énoncé

Concevez un système à trois agents pour produire une synthèse sourcée : recherche, rédaction, vérification. Définissez les entrées, sorties, droits et traces de chaque agent.

## Ce que l'exercice vérifie

L'exercice vérifie la séparation de responsabilités dans un système multi-agent. Plusieurs agents ne suffisent pas : il faut des contrats.

## Solution détaillée

### Agent Recherche

Entrée :

```text
question, filtres, permissions
```

Sortie :

```text
liste de sources avec extraits, scores, dates, versions
```

Droits :

- lecture corpus autorisé ;
- pas de génération finale ;
- pas d'écriture mémoire.

Traces :

- requête ;
- documents candidats ;
- scores ;
- documents exclus.

### Agent Rédaction

Entrée :

```text
question + sources sélectionnées
```

Sortie :

```text
synthèse avec citations
```

Droits :

- générer un brouillon ;
- ne pas appeler de sources non autorisées ;
- ne pas inventer de citation.

Traces :

- sources utilisées ;
- passages cités ;
- version du prompt.

### Agent Vérification

Entrée :

```text
brouillon + sources
```

Sortie :

```text
validation, corrections, refus ou demande de recherche complémentaire
```

Droits :

- rejeter la réponse ;
- demander plus de sources ;
- marquer claims non supportés.

Traces :

- claims vérifiés ;
- sources support ;
- erreurs détectées.

## Points importants

- Recherche, rédaction et vérification ont des droits différents.
- La vérification doit pouvoir bloquer la sortie.
- Les sources doivent être traçables.
- Les permissions s'appliquent dès la recherche.
- Un budget global évite les boucles.

## Prolongement

Le système doit prévoir un arbitrage : si vérification et rédaction divergent, la sortie finale doit privilégier la source et la politique, pas le texte le plus fluide.
