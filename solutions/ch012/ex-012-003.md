# EX-012-003 - Coût quadratique et coût linéaire

## Énoncé

Comparez qualitativement le coût d'une attention standard et d'un scan SSM pour des séquences de longueur `1 000`, `10 000` et `100 000`.

## Ce que l'exercice vérifie

L'exercice vérifie la différence de croissance. L'attention dense compare les positions entre elles. Un scan SSM maintient un état et avance le long de la séquence.

## Solution détaillée

Pour l'attention standard dense, le nombre de relations token-token croît comme :

```text
O(n^2)
```

Pour un scan SSM, si la dimension d'état et les autres dimensions restent fixes, le coût séquentiel de base croît plutôt comme :

```text
O(n)
```

Comparons qualitativement.

| Longueur | Attention dense | Scan SSM |
|---:|---:|---:|
| `1 000` | environ `1 000 000` relations | environ `1 000` pas |
| `10 000` | environ `100 000 000` relations | environ `10 000` pas |
| `100 000` | environ `10 000 000 000` relations | environ `100 000` pas |

La différence devient énorme quand `n` augmente.

Mais il faut rester rigoureux. Cette comparaison ne suffit pas à prédire la performance réelle. Les constantes comptent :

- dimension cachée ;
- nombre de têtes ;
- taille de l'état ;
- kernels optimisés ;
- parallélisation ;
- mémoire GPU ;
- batch ;
- précision numérique ;
- framework.

Un SSM mal implémenté peut être moins performant qu'une attention optimisée sur certaines longueurs. Une attention très optimisée peut rester excellente sur des contextes moyens. Le point est donc structurel, pas absolu.

## Points importants

- L'attention dense croît comme `n^2`.
- Le scan SSM peut croître comme `n` si les dimensions restent fixes.
- La différence devient majeure sur très longues séquences.
- Les constantes et l'implémentation réelle comptent.
- Le coût théorique ne remplace pas un benchmark.

## Prolongement

Dans un vrai système, on compare aussi la qualité. Un SSM peut être moins coûteux sur longue séquence, mais si la tâche demande de retrouver un détail exact très éloigné, une attention ou une mémoire externe peut rester nécessaire.
