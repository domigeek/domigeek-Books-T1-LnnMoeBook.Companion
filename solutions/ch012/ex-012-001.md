# EX-012-001 - Lire une équation d'état

## Énoncé

Expliquez en prose les équations `s_t = A_bar*s_{t-1} + B_bar*u_t` et `y_t = C*s_t + D*u_t`.

## Ce que l'exercice vérifie

L'exercice vérifie la lecture d'un State Space Model discret. Le but est de comprendre les rôles : état, entrée, transition, injection et sortie.

## Solution détaillée

La première équation est :

```text
s_t = A_bar*s_{t-1} + B_bar*u_t
```

Elle décrit la mise à jour de l'état latent.

`s_t` est le nouvel état au temps `t`. `s_{t-1}` est l'état précédent. `u_t` est l'entrée courante.

`A_bar` décrit comment l'ancien état évolue vers le nouvel état. C'est la partie "mémoire" ou "dynamique interne" du modèle.

`B_bar` décrit comment l'entrée courante influence l'état. C'est la porte d'entrée du signal externe dans la dynamique.

Lecture simple :

```text
nouvel état = ancien état transformé + entrée courante injectée
```

La deuxième équation est :

```text
y_t = C*s_t + D*u_t
```

Elle décrit comment produire la sortie.

`C` lit l'état latent pour produire une sortie. `D` permet une contribution directe de l'entrée courante à la sortie.

Lecture simple :

```text
sortie = lecture de l'état + effet direct de l'entrée
```

Le terme `D*u_t` n'est pas toujours le personnage principal, mais il est utile dans certains systèmes : il permet à l'entrée courante d'influencer directement la sortie sans passer uniquement par l'état.

## Points importants

- `s_t` est un état latent.
- `A_bar` transporte ou transforme l'état précédent.
- `B_bar` injecte l'entrée dans l'état.
- `C` lit l'état pour produire la sortie.
- `D` ajoute un chemin direct de l'entrée vers la sortie.

## Prolongement

Les SSM modernes rendent ces idées efficaces à grande échelle grâce à des paramétrisations, des scans parallèles et des optimisations matérielles. Mais l'intuition de base reste celle-ci : maintenir un état compact qui évolue avec la séquence.
