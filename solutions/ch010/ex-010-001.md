# EX-010-001 - Lire la update gate

## Énoncé

Expliquez en prose l'équation `h_t = (1 - z_t) * h_{t-1} + z_t * g_t`.

## Ce que l'exercice vérifie

L'exercice vérifie la lecture de la porte de mise à jour d'un GRU. Cette équation décrit un mélange contrôlé entre l'ancien état et un nouvel état candidat.

## Solution détaillée

L'équation est :

```text
h_t = (1 - z_t) * h_{t-1} + z_t * g_t
```

`h_{t-1}` est l'ancien état caché. `g_t` est le candidat proposé pour le nouvel état. `z_t` est la porte de mise à jour.

Si `z_t` est proche de `0`, alors :

```text
h_t ≈ h_{t-1}
```

Le modèle conserve surtout l'ancien état.

Si `z_t` est proche de `1`, alors :

```text
h_t ≈ g_t
```

Le modèle remplace davantage l'ancien état par le candidat.

Si `z_t` est entre les deux, le nouvel état est un mélange.

L'opération est composante par composante. Certaines dimensions peuvent être conservées, d'autres réécrites.

Lecture simple :

```text
z_t décide combien on garde de l'ancien état
et combien on accepte du nouveau candidat
```

## Points importants

- `z_t` contrôle le mélange.
- `h_{t-1}` représente l'ancien état.
- `g_t` propose un nouvel état.
- Le mélange est différentiable.
- Le GRU utilise un seul état principal, contrairement au LSTM qui sépare `c_t` et `h_t`.

## Prolongement

Cette équation donne au GRU un mécanisme de continuité. Il peut choisir de changer peu quand le contexte reste stable, ou de changer davantage quand une nouvelle information devient importante.
