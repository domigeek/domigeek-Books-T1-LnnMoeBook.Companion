# EX-010-004 - Protocole de comparaison

## Énoncé

Proposez un protocole minimal pour comparer un GRU et un LSTM sur une série temporelle.

## Ce que l'exercice vérifie

L'exercice vérifie la rigueur expérimentale. Comparer deux architectures demande plus qu'un entraînement rapide sur un seul split.

## Solution détaillée

Un protocole minimal devrait fixer le dataset et la tâche.

Exemple :

```text
tâche : prédire la valeur ou la classe au pas suivant
données : série temporelle multivariée
split : train, validation, test en respectant l'ordre temporel
```

Il faut éviter de mélanger le futur dans le passé. Pour une série temporelle, le split doit respecter la chronologie.

Ensuite, on définit deux modèles comparables :

```text
GRU avec budget de paramètres proche
LSTM avec budget de paramètres proche
```

Comparer un petit GRU à un LSTM deux fois plus gros ne teste pas seulement la cellule. Cela teste aussi la capacité.

On fixe :

- même normalisation ;
- même longueur de fenêtre ;
- même batch size si possible ;
- même budget d'entraînement ;
- même optimiseur ou recherche comparable ;
- même scheduler ;
- mêmes métriques ;
- plusieurs seeds si le budget le permet.

Métriques possibles :

```text
MAE ou RMSE pour régression
accuracy, F1 ou AUC pour classification
latence d'inférence
mémoire
temps d'entraînement
stabilité validation
```

Le protocole doit aussi inclure une baseline simple :

```text
prédire la dernière valeur
moyenne mobile
MLP sur fenêtre fixe
```

Si les architectures récurrentes ne battent pas une baseline simple, c'est une information importante.

## Points importants

- Respecter l'ordre temporel.
- Comparer des budgets de paramètres raisonnablement proches.
- Utiliser les mêmes splits et métriques.
- Mesurer qualité et coût.
- Ajouter une baseline simple.
- Utiliser plusieurs seeds si possible.

## Prolongement

Une conclusion correcte pourrait être :

```text
Sur ce dataset, avec ce budget et ces métriques, le GRU obtient une performance similaire au LSTM avec moins de coût.
```

Elle ne devrait pas être :

```text
Le GRU est meilleur que le LSTM.
```

La nuance fait toute la différence.
